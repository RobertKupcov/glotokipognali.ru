# ГЛОТОК — сайт-визитка (HTML + CSS)

Сайт для бренда живой комбучи «ГЛОТОК»: главная страница, галерея вкусов, контакты. Статический сайт — без CMS и баз данных.

## Что внутри

- `index.html` — разметка страницы (заголовки, карточки вкусов, блок контактов).
- `style.css` — стили (сетка галереи, адаптив, цвета, отступы).
- `img/` — папка с изображениями продукции. Сюда нужно положить фото бутылок и срезов вкусов.

## Как запустить на GitHub Pages

1. Загрузить файлы в репозиторий (обязательно положить `index.html` в корень).
2. В настройках (Settings → Pages) выбрать ветку `main` (или `master`) и папку `/ (root)`.
3. Сохранить — сайт появится по ссылке вида `glotok.github.io`.

## Важные нюансы

- **Регистр букв важен.** Файлы `OguRec.jpg` и `ogurec.jpg` — это разные файлы на GitHub. Имена в коде и в папке должны совпадать буква в букву.
- **Пути к картинкам.** В коде должно быть: `<img src="img/ogurec-myata.jpg" alt="...">`. Не ставь слэш в начале (`/img/...`) — иначе картинки не загрузятся.
- **SEO.** В `index.html` уже прописаны title, description, alt-тексты и canonical.
